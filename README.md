# 🧟‍♀️ eggZom

> 미소녀 좀비 방치형 로그라이크 — 브라우저에서 바로 돌아가는 싱글 파일 게임

당신은 **0번째 감염자**. 귀여운 좀비 소녀들을 이끌고 인류 최후의 방어선을
웨이브 단위로 무너뜨립니다. 전투는 전부 자동이고, 당신이 할 일은
**무엇을 강화할지 고르는 것**뿐입니다.

```
index.html 을 브라우저로 열면 끝. 설치도, 빌드도, 서버도 필요 없습니다.
```

---

## 플레이 방법

| 조작 | 설명 |
|---|---|
| 자동 전투 | 편성한 소녀들이 알아서 싸웁니다 |
| `1` `2` `3` | 액티브 스킬 즉시 사용 (자동 시전도 켜져 있음) |
| 탭 클릭 | 강화 / 부대 / 유물 / 유전자 |

## 게임 시스템

### 🧠 뇌수 — 끝없는 강화
적을 처치하면 뇌수가 떨어집니다. **강화** 탭의 8종 스탯은 상한 없이 계속
올라가며, `x1 / x10 / MAX` 로 한 번에 지를 수 있습니다.

### 👑 보스 — 10웨이브마다 벽
10웨이브마다 지역 보스가 등장합니다. 제한 시간 안에 잡지 못하거나
🛡️ **방벽**이 무너지면 최대 3웨이브 뒤로 후퇴합니다.
보스를 잡으면 🦴 뼈와 **유물 선택권**을 얻습니다.

### 🔮 유물 — 로그라이크의 핵심
보스를 처치할 때마다 무작위 3장 중 **1장만** 고릅니다. 26종의 유물이
서로 다르게 맞물리며, 회차마다 전혀 다른 빌드가 됩니다.

> 「태엽 심장」공속 +22% / 공격력 −6% · 「저주받은 인형」공격력 +30% / 방벽 −10%
> 「끓는 혈액」방벽 50% 이하일 때 공격력 +60% · 「역행의 모래」중첩 무제한

유물은 **재감염하면 전부 사라집니다.** 매 회차가 새 판입니다.

### 🧬 재감염 — 영구 성장
WAVE 25 이상에서 재감염하면, 도달한 최고 웨이브에 비례해 **유전자**를 얻습니다.
유전자로 찍는 12종 노드는 **영구히** 남습니다 — 부대 슬롯(3→5칸), 유물 선택지(3→5장),
방치 효율, 보스 피해 등.

- **초기화**: 웨이브 · 뇌수 · 강화 · 유물 · 소녀 레벨
- **유지**: 보유 소녀 · ⭐성급 · 뼈 · 유전자 · 유전자 노드

### 👯 부대 — 8인의 좀비 소녀
🦴 뼈로 **감염 소환**을 돌려 소녀를 모읍니다. 중복은 조각이 되어 ⭐승급(최대 5성)에
쓰입니다. 편성한 소녀의 패시브는 **팀 전체**에 적용되므로 조합이 곧 빌드입니다.

| 소녀 | 등급 | 역할 | 패시브 (레벨당) |
|---|---|---|---|
| 미라 | R | 근접 | 팀 공격력 +1.0% |
| 네코 | R | 연타 | 팀 공격속도 +0.8% |
| 비비 | R | 지원 | 🧠 획득량 +2% |
| 루비 | SR | 원거리 | 치명타 확률 +0.4%p |
| 하루 | SR | 수호 | 방벽 최대치 +3% |
| 유키 | SR | 둔화 | 치명타 피해 +2% |
| 노바 | SSR | 광역 | 전염 폭발 확률 +0.5%p |
| 세라 | SSR | 신성 | 보스 피해 +1.8% |

### 🌙 방치
게임을 꺼둬도 **최대 12시간**까지 뇌수가 쌓입니다 (기본 효율 35%, 유전자로 상승).
돌아오면 정산 화면이 맞아줍니다. 진행 상황은 `localStorage`에 자동 저장됩니다.

## 기술 메모

외부 라이브러리도, 이미지 파일도 **하나도 쓰지 않습니다.**
캐릭터·적·배경·이펙트까지 전부 Canvas 2D 로 코드에서 직접 그립니다.

```
index.html          화면 골격
assets/style.css    다크 파스텔 테마 · 반응형(모바일 대응)
src/data.js         유닛 · 유물 · 강화 · 유전자 · 지역 데이터
src/assets.js       외부 일러스트 로더 (없으면 코드 드로잉으로 폴백)
src/state.js        저장/불러오기 · 파생 스탯 계산 · 성장 곡선
src/engine.js       전투 시뮬레이션 (스폰 · 타겟팅 · 데미지 · 웨이브)
src/render.js       Canvas 렌더러 (절차적 미소녀 드로잉 포함)
src/ui.js           탭 · 강화 · 부대 · 소환 · 유물 선택 · 재감염
src/main.js         부트 · 고정 timestep 루프 · 방치 정산
art/manifest.js     교체할 일러스트 목록
docs/art-prompts.md 일러스트 외주용 프롬프트 키트 (설명서)
docs/prompts/        조립 완료된 복붙용 프롬프트 26종
tools/build-prompts.js  data.js 를 읽어 프롬프트를 생성
```

- **고정 timestep(1/60초)** 으로 프레임률과 무관하게 동일한 밸런스를 보장합니다.
- 캔버스는 가상 해상도 `960×470` 을 `contain` 으로 매핑하고, 남는 여백까지
  배경을 이어 그려 레터박스가 보이지 않습니다.
- 개발용 시뮬레이터가 들어 있습니다. 콘솔에서:

```js
ZDEV.sim(600, true)   // 600초를 즉시 시뮬레이션 (자동 구매 포함)
ZDEV.autobuy()        // 가장 싼 강화를 가능한 만큼 구매
ZDEV.grantRelic('fang')
```

### 밸런스 기준선
1인 편성 + 자동 구매만으로 돌린 시뮬레이션 결과:

| 경과 | 웨이브 | 비고 |
|---|---|---|
| 1분 | 5 | |
| 3분 | 11 | 첫 보스 격파 |
| 9분 | 25 | 재감염 해금 |
| 30분 | 47 | 보스 4마리 · 후퇴 11회 |

## 아트 제작

캐릭터·배경 일러스트를 외부 이미지 AI로 뽑기 위한 프롬프트 키트가
[`docs/art-prompts.md`](docs/art-prompts.md) 에 있습니다. 인게임 색상 hex 를
그대로 박아둬서, 받은 일러스트가 현재 UI 팔레트와 그대로 맞습니다.

조립이 끝난 복붙용 프롬프트 26종(카드 8 · SD 8 · 배경 10)은
[`docs/prompts/`](docs/prompts/) 에 있습니다. 게임 색을 바꾸면
`node tools/build-prompts.js` 로 다시 뽑으면 됩니다.

그림이 나오면 **코드 수정 없이** `art/` 에 파일을 넣고 `art/manifest.js` 에
이름만 적으면 됩니다. 전장 아바타는 SD(2.5등신), 캐릭터 카드는 전신 일러로
분리되어 있고, 없는 항목은 코드 드로잉으로 자동 폴백합니다.

```js
window.ZOM_ART = { chibi: ['mira'], bust: ['mira'], full: ['mira'], bg: [1] };
```
